# 领域文档约定

本仓是单一上下文：根目录 `CONTEXT.md` 是词汇表，`docs/adr/` 放架构决定。

## 读

- 探索代码、设计接口或写规范前，先读 `CONTEXT.md` 里相关的词条和相关的架构决定。
- 文件不存在就跳过，不为凑齐目录建空文件。

## 写

- `CONTEXT.md` 一条一个术语：定义、常见别名、出处（文件或决定）。只收已经确认的项目概念；任务状态、实施步骤、验收标准不进词汇表。
- 架构决定用中文写，结构为：标题、状态、背景、决定、后果。编号顺延，不改已有编号。

## 冲突

代码、需求或讨论里的叫法和词汇表不一致，或者和已有架构决定冲突时，明确指出冲突，请用户决定；决定后更新词汇表或补一条架构决定。
